# Code of Conduct

## Our Standards

This project is maintained by the Volcengine PostgreSQL team. We expect all
participants in project discussions and internal reviews to communicate
respectfully, provide actionable feedback, and focus on the technical problem.

Unacceptable behavior includes harassment, discrimination, personal attacks,
deliberate disclosure of credentials or private information, and any conduct
that violates applicable company policies.

## Scope

This code of conduct applies to project issues, reviews, design discussions,
documentation, and other project-related communication channels.

## Reporting

External code contributions are not currently accepted. For internal project
conduct concerns, contact the project owner or the responsible manager through
the company's internal reporting process.

## Enforcement

Project maintainers may remove content or restrict participation when conduct
violates these standards. Serious security or privacy concerns must be reported
through the process described in `SECURITY.md`.
